# 文档输入

导入支持本机绝对路径的 Markdown、TXT 文件和目录。目录递归枚举，包含隐藏文件；不跟随符号链接。重复路径和不支持的文件会给出诊断。

文档身份按知识库和来源路径确定：同路径再次导入是更新，移动或改名默认新增。需要延续原身份时使用 `/knowledge reimport <文档UUID> <新路径>`。

每批先固定文件清单，再保存各文件的完整原件。后续解析和恢复读取这些归档；源文件的修改、移动或删除不会改变已保存版本。

开启持续同步使用[watch 命令](codeplus-integration.md)。源文件删除不会自动删除知识库文档，需要显式执行 remove。
