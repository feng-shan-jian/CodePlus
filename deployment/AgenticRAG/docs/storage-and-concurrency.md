# 数据存储

知识库使用独立的本机数据目录，路径通过 `knowledge.storage.data_dir` 配置。Milvus 保存检索索引，本地目录保存资料与版本记录。

| 位置 | 内容 |
| --- | --- |
| `catalog.sqlite` | 库、文档版本、发布记录、任务和引用 |
| `archives/` | 原件、解析文本及来源位置，以内容 hash 存储 |
| `staging/` | 尚未完成的归档写入 |
| `locks/` | 本机并发协调文件 |

同一库一次执行一项导入、删除或重建；查询继续使用已发布版本，不同库可独立修改。中断批次占用修改入口，处理方式见[恢复](manual-recovery.md)。

当前数据库为 schema12，打开时自动升级受支持的旧版本。资料归档与历史引用长期保留，旧检索索引由[生命周期维护](index-lifetimes.md)回收。不要手工删除正在使用的数据库、WAL/SHM 或锁文件。
