# 来源读取与引用

搜索结果指向任务绑定版本的原文。Agent 可打开命中章节，通过章节导航和游标继续阅读前后内容；长文按单次正文上限分页。返回内容带文件、章节、行号和原文区间。

来源工具返回正文后，宿主记录它在实际模型请求中的交付情况。成功交付的原文区间可用于引用；仅命中的候选和未发送正文不计入已交付证据。

```text
/knowledge open <引用UUID>
```

open 支持当前 evidence UUID 和历史 citation UUID，从对应版本归档读取原文。源文件修改、删除或旧检索索引回收后，历史引用仍可查看。

普通 Agent 负责生成回答和引用。compact 可以移除当前上下文中的正文，历史交付记录和引用仍保留。
