## 实现结果与接口

详细契约见 [解析与来源映射](../parsing-and-source-maps.md)。规范文本保留 Markdown 和 Unicode 原码点，只移除起始 BOM 并统一 CRLF/CR；映射保存逐码点原始字节边界及一基行号，无替换解码，无重复文本搜索反推。结构使用 markdown-it-py 4.0.0 的行 map 加真实 offset，TXT 按空行合段；section 自身分区与 heading 父子/subtree 范围同时保留。空文件/纯空白/仅标题不伪造空 Span 或模型输入。

分块按结构/句子/token 候选边界；中文无空格断句、TXT 软换行、长 fence/table/list、NFC offset 空隙及 emoji 重叠均保留精确原文。预先定位 heading 导航范围之外的非空白码点，确保每片有实际正文；过长空白或标题导航缺口单独记账，canonical 永久保留。覆盖分母来自解析后的正文范围及独立非空白原文，而非输出 Chunk；非导航正文缺口直接失败。重叠范围与实际 token 可复算。

`models.FrozenTokenizer` 按 profiles 的四份文件 hash 和精确 revision 加载实际 tokenizers 0.23.2；不导入 probes 或 Transformers/Torch。Embedding 完整 Title/body + 实际 EOS 151643 重编码；Rerank 保持自己的 tokenizer、query 和 prefix/inner/suffix 各段编码。R08 512/64 是试验参数，完整模型上限保持2048，标题无正文余量/超限明确诊断，不截断。R09 可直接复用 `document/query/rerank → ModelSequence(ids,pieces,token_count)`。

`process_inputs` 只读取 R07 已归档原件及该批已存配置。真实 parsed/source_map/chunks 归档和全部内容验证/序列化在 SQL 外；一个 owner/epoch 短事务登记 DocumentVersion、完整 sections/chunks 与唯一 ImportItem 检查点。迁移3保留旧两份 SQL 字节，完成结构不可追加。`read_processed` 校验输入/版本/配置、hash、映射和完整数据库集合，完成结果重开复用不再跑 Markdown/chunker。R07 raw 结果不变，孤儿/半元数据不能复用。
