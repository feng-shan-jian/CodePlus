## 行为与范围

完整运行 pin、Dense 模型到 SDK 的跨调用占用、直接 SDK 读取及向量复用进入同一个 reader/GC 事务协议；终态运行在真实读取结束后释放。复用 R14 的 mutation IO、artifact 原生锁与物理所有权凭证，增加 schema9 生命周期事实及有界轮转维护。当前版、旧运行、非终态构建/恢复与未知 IO 均阻止物理删除；旧 PUBLISHED 可回收，publication receipt 和全部历史归档保留。

RequestHandle 仅增加本次认证 worker 身份快照，并让完成等待使用该冻结身份。没有引入独立 W2 的 session 轮换、payload 回收或诊断扩展。自动维护、Scope 退役、失败退避、核心安装不引入 GPU/Milvus、SDK 条件删除的边界见 [索引生命周期](../index-lifetimes.md)。

发布、放弃、运行/读取释放及适配器接入会触发维护；默认每轮最多两次物理尝试，reader/pin 16 行、artifact 最多 32 行轮转；有适配器时两秒续轮，失败退避最多 60 秒。close 立即拒绝新业务读取，有限退役只覆盖 close 时已有对象；`wait_closed` 才是实际连接关闭证据。
