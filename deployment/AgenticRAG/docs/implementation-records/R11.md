## 实现和范围

新增 `source_archive.py`、`sources.py`、`evidence.py`、`citations.py` 和追加 migration5 `storage/evidence.sql`，复用既有 SourceRef/Evidence/Citation DTO、RunLease、ArchiveStore、ChunkSet、SourceMap 和实际 DenseSearch。原 SourceRef 五 UUID、SQL1–4、ProcessingSnapshot、RunConfiguration 与旧输入快照保持兼容。domain 只补充可区分的错误枚举；RunLease.finish 使用数据库最新 usage，避免旧 lease 内存覆盖本轮工具计数。没有新增 Agent、产品入口、主模块接点、根依赖或旧库兼容层。

归档读取固定 run revision 的成员，核对原件、canonical、SourceMap、ChunkSet 和 section own-span，不依赖当前源路径。默认命中由验证后的 Dense chunk anchor 定位；显式 section 从自身区间起点读取。随机不透明 source/cursor 保存于服务端，绑定 run、库、版本、章节、位置和 cursor 的 range_end。前后续读范围互不越界；未读区间明确表示“尚未被来源工具返回”，不等同 confirmed 资格。每页只输出一个导航节点和邻接位置，240 个短章节的小窗口可以逐个遍历。

`.payload` 是机器元数据；`.text` 才是实际交付文本，正文保持 canonical 码点，`.body_mappings` 在拼接时生成。工具成本按同一文本计量。DeliveryGateway 只接受可信宿主能力，对最终 HTTP JSON 的合法 tool-result 节点、同节点 ID、精确 source/body 范围和 hash 独立校验；不通过 find 反推位置。只有 confirmed 且非 compact 的实际映射增加 Evidence，未送达部分和间隙不能引用。当前窗口、历史返回成本、历史 confirmed 资格独立记账；明确裁剪后的可信宿主同步可以腾退窗口，旧 generation 不能丢弃新预留。

CitationRegistry 程序核验 run/version/member/section/ranges/quotes，区分未确认位置和摘录字符不符；保存稳定脚注，显式转换 provisional evidence marker 到 citation marker。历史引用允许 terminal run，只依赖归档；展示的文件名、URI、章节和行号也重新核对权威记录。单条派生 Evidence payload 损坏时从 sealed confirmed receipts 重算范围，拒绝偏离既有回执。该受控存储损坏检测不表示模型拥有数据库写权限，也不承诺防御同用户重写整个数据库。

接口、信任边界与 R12 接入责任见 [sources-and-evidence.md](../sources-and-evidence.md)。资料目录/评分/路径/摘要/history 不授新资格，terminal active-run 授权与历史 Citation 回看是不同路径。renderer 将全部 `[^...]` 保留为引用语法，包括代码示例；宿主不应把这些语法当普通文本透传。
