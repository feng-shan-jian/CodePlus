## 实现与合同坐标

原 `Agent.run` 和 `Agent.run_to_completion` 两个循环接收默认 None 的可选 execution policy；独立包不另建 Agent 或 LLM 循环。策略固定 library/revision、模型、预算和 pin，装配仅 search/open 的 registry。TUI `/knowledge use/ask/off` 和原 `-p --knowledge-library` 是显式开发接点，普通文本不因选库而自动转成知识库请求。Remote 返回明确不可用，完整产品命令、报告、auto 模式与迁移保留后续任务。

两入口在知识库 scope 中隔离 memory prefetch/摘要/退出提取、coordinator/team、通知/mailbox、MCP/普通工具、恢复附件与环境再注入；普通调用默认路径保留。可执行/异步 hooks 启动前明确拒绝，同步 prompt hooks 进入完整输入计量。知识库取消收束结束前 UI 保持 busy；权限 future 在 yield 前登记，widget 事件按原 future 身份绑定，旧事件不能批准后续请求。

可信 source sidecar 穿过单条/合计 spill、history、pair repair、compact 和三协议 serializer。最终 HTTP hook 针对实际 bytes 核对 JSON path、call ID、区间和 hash；Anthropic content_blocks 以实际传输字段为准。被删正文、路径/wrapper、错误、摘要不能授权证据。compact 不新增资格，已 confirmed 的同 run 资格与当前上下文窗口独立保存。

三协议请求各用 scope 专属 SDK/HTTP 客户端、禁隐藏重试/重定向、带输出硬 cap；SDK stream 和入口消费者均收束。raw usage、协议 terminal/details、transport 状态与 Evidence receipt 分开记录。合法截断可证明输入送达，但不发布答案；失败/拒绝/未知终态不获得新 Evidence。明确供应商失败落为 failed/explicit_error，保留真实失败事实，成功/合法截断缺失或变化的模型身份失败关闭。

模型正文/思考先内部缓冲。引用先验证 JSON shape、每个 citation 的每个 span/quote，以及 Markdown marker/重复 claim 的完整关联，全部通过才 save/render。marker 规则由核心同一纯验证方法供 adapter 和 renderer 复用。所有脱敏错误定位一次反馈给同一个 Agent，最多一次 tools=[] 修正；失败零发布，无截断/规范化引文后冒充通过。

真实 task-owner 同时跟踪 asyncio Task、权限 Future、executor concurrent Future 和 GPU RequestHandle。取消先关闭 admission，再结算请求、撤销权限及有界 drain。同步 worker 握手锁/取消 IPC 不阻塞事件循环；实际读者未完成则 terminal + cleanup_pending 且保 pin，真实 worker_finished 后才 release。若消费者取消到达时终态已持久化，则传播取消而不改写已经提交的终态；内存 outcome 与数据库一致。

## 模型、预算与试验值

详情及机制证明见 [R12-budget-design.md](R12-budget-design.md)。用户两个配置别名保持 deepseek-chat/deepseek-reasoner，真实响应为 deepseek-flash，当前官方族为 DeepSeek-V4.1-Flash。别名默认模板不同，同一简单输入分别 14/40 tokens，不能只按 response.model 选模板。

官方模板固定 revision `dba1be0a40aa45a94ad051997016db3960a90277`；encoder SHA256 `502bdaec8a3fd88ebc24c4721a7038fbe42f2063c664638127056107920035c1`，tokenizer SHA256 `c90dfa01249db1be4245780a052ede752e1361c612ac6d08e2bdada7d599476b`。encoder 必要纯 Python 代码带 MIT 归属，tokenizer/权重不提交。完整官方模板 UTF-8 bytes 是有机制依据的保守上界，**不是精确 token 数**；不使用经验字符除数、Embedding tokenizer 或测试 byte fixture 冒充生产计量。

chat 与 reasoner 各 10 个完整 payload 网络校准：各 9 个精确对齐；特殊控制 token 字面量样本差 111，原失败事实保留。生产递归拒绝 pinned added-token 字面量，包括 keys/schema 和 arguments 的二次 JSON 解析结果；普通 Unicode 支持。未知模型/端点/字段/多模态/远程状态失败关闭，不换用户模型。

每个 HTTP 请求预留完整输入 U+输出 cap；unknown total 保留预留，已知违规保留真实数值。探索不能消耗两个收尾槽位（finalize + citation_repair）的完整输入与输出预算。deadline 自 run 开始，覆盖装配/排队/权限/工具/compact；同步计量跨过 deadline 时，最后 HTTP 门 not_sent、退回模型预留、transport 调用为零。source-return、accepted search/open 与模型 token 各自计量，不重复累计。

合成真实链路配置：3 文档/3 chunks，fixed Dense、rerank=false；QA 200000 tokens/300000 ms，finish reserve 32000 tokens/30000 ms，两个 finish 输入上界各 12000，各输出 cap 2048，探索/compact cap 2048，max_iterations 20、tool attempts 40、正常 cleanup grace 1000 ms。初始 context_chunks=8 被四次 search 占满，两个 open 均 error；[trial 02](R12-trial-config-02.json) 只把显式 context_chunks 改为16，产品默认 auto、索引身份及其他值不变。GPU 取消用例单独用10 ms grace，以观察真实未完成读者；这些都是实测开发试验值，不是 R24 质量参数冻结。
